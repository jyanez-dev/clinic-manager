🧾 ClinicManager – Project Summary
📌 General Overview

ClinicManager is a scalable medical management system designed to support multiple doctors, patients, appointments, and medical records.
The backend is built using ASP.NET Web API + Entity Framework Core + SQL Server.

🗄️ Database
SQL Server database: ClinicManagerDB
Designed for scalability (multi-doctor / multi-user)
Tables implemented:
Users, Roles, UserRoles
Doctors
Patients, DocumentTypes
Appointments, AppointmentStatus
MedicalRecords, RecordTypes
🧩 Backend Architecture
ASP.NET Web API project
Entity Framework Core (Code First approach)
DbContext configured with SQL Server
Models representing all database tables
Relationships properly configured (1:1, 1:N, N:N)
🌐 API Features
RESTful API structure
Controllers with full CRUD support
Dependency Injection for DbContext
Swagger (OpenAPI) enabled for testing endpoints
