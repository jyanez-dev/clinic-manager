Proyecto ClinicManager – Resumen de progreso
1️⃣ Estructura del proyecto
Carpeta principal: ClinicManager.API
Subcarpetas creadas:
Models → Contiene las 10 clases que representan tus tablas de la base de datos.
Data → Contiene ClinicManagerDbContext.cs, la clase de EF Core que conecta los modelos con SQL Server.
Controllers → Vacía, será donde crearás los endpoints Web API.
Archivos de configuración:
appsettings.json → Cadena de conexión a la base de datos y logging.
appsettings.Development.json → Configuración específica de desarrollo.

Base de datos creada: ClinicManagerDB en SQL Server.
Tablas creadas y scripts listos:
Users, Roles, UserRoles
Doctors, DocumentTypes, Patients
AppointmentStatus, Appointments
RecordTypes, MedicalRecords
Cada tabla tiene su clase correspondiente en Models.

Relaciones de navegación implementadas donde corresponde (ICollection<> o referencias 1:1).
Nullable (?) usado para campos opcionales.
